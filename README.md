
# Classificação de Notas

## 1. Objetivo
Desenvolver um programa em C que organize dez notas fictícias de alunos em ordem decrescente, utilizando Bubble Sort e Quick Sort.

## 2. Contextualização
A organização de notas facilita a visualização do desempenho acadêmico. Este programa demonstra como algoritmos de ordenação podem ser utilizados para organizar notas da maior para a menor.

## 3. Tecnologias utilizadas
- Linguagem C
- GDB Online
- Git e GitHub

## 4. Algoritmos utilizados

### Bubble Sort
Compara elementos vizinhos e realiza trocas quando estão na ordem incorreta. Neste programa, as maiores notas ficam primeiro.

### Quick Sort
Utiliza um pivô para particionar os elementos e ordenar recursivamente os grupos, colocando as maiores notas primeiro.

## 5. Como executar
1. Acesse https://www.onlinegdb.com/online_c_compiler
2. Selecione C.
3. Cole o código do arquivo main.c.
4. Clique em Run.
5. Confira as notas originais e os resultados dos dois algoritmos.

## 6. Resultados
O programa exibe as dez notas originais e as sequências ordenadas pelos dois algoritmos.
